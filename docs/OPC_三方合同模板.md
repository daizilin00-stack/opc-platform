## 第三条 各方权利与义务

### 3.1 甲方（发包方）

**权利**：
1. 要求乙方按合同约定时间、质量标准交付；
2. 对里程碑及最终交付成果进行验收，有权要求整改；
3. 在乙方严重违约时，要求丙方协助处理及按约扣款。

**义务**：
1. 按约定时间支付款项（或支付至托管账户）；
2. 在__个工作日内完成需求确认及答疑；
3. 按里程碑节点及时验收，无故拖延不得超过__个工作日；
4. 为乙方提供必要的配合（数据、接口、测试环境等）。

### 3.2 乙方（接包方）

**权利**：
1. 按约定收取项目款项；
2. 要求甲方提供必要配合及明确需求；
3. 在甲方逾期付款或需求重大变更时，要求顺延工期或调整费用。

**义务**：
1. 按合同约定时间、质量标准完成交付；
2. 每周向丙方报送项目进度，接受丙方过程管控；
3. 对甲方提供的商业秘密、数据严格保密；
4. 质保期内对缺陷免费修复；
5. **承诺不绕过丙方与甲方私下直接交易后续需求**（违约者丙方有权降级/清退并追偿）。

### 3.3 丙方（平台方）

**权利**：
1. 按本合同约定收取撮合服务费；
2. 对项目进度进行监督、协调；
3. 在乙方严重违约时，有权暂停付款并介入调解；
4. 使用项目脱敏信息作为平台案例（需征得甲乙双方同意）。

**义务**：
1. 为甲乙双方提供需求拆解、标准合同、过程管理工具；
2. 对托管资金专款专用，不得挪作他用；
3. 在收到甲乙双方一致确认的验收通知后__个工作日内完成放款；
4. 对争议进行调解，调解不成不承担责任（可协助双方走法律途径）。
