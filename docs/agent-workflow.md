## 三、Agent 间通信协议

### 3.1 消息格式（内部标准）

```json
{
  "from": "agent-sales",
  "to": "agent-ceo",
  "type": "escalation | handoff | report | request",
  "task_id": "task_12345",
  "context": {
    "partner_id": "user_67890",
    "client_id": "client_11111",
    "issue_summary": "客户要求定制 SLA 条款",
    "urgency": "medium"
  },
  "payload": "具体内容...",
  "timestamp": "2026-05-29T09:00:00+08:00"
}
```

### 3.2 调用方式

在 OPC 平台内，Agent 间通过以下方式协作：

1. **同步调用**：`agent-ceo` 直接派单给具体 Agent，等待返回结果
2. **异步通知**：`agent-assistant` 定时推送提醒，不阻塞主流程
3. **事件广播**：`agent-compliance` 发现政策变动，广播给全体相关 Agent

## 四、知识库分层

| 层级 | 内容 | 维护者 | 更新频率 |
|------|------|--------|----------|
| **公司层** | 中新数据港产品手册、价格体系、SLA | agent-ceo | 产品变更时 |
| **法规层** | 中新两地数据法规、合规清单、模板合同 | agent-compliance | 政策变动时 + 每周巡检 |
| **技术层** | 专线技术文档、API 手册、故障排查 SOP | agent-solution | 技术迭代时 |
| **销售层** | 话术库、竞品对比、成功案例 | agent-sales | 每月更新 |
| **客服层** | FAQ、工单处理模板、客户画像 | agent-support | 每周更新 |

## 五、人机协作边界

| 场景 | AI Agent 做 | 人类（董事长/创业者）做 |
|------|-------------|----------------------|
| 客户初筛 | 自动应答、需求分类、方案初稿 | 高价值客户最终谈判 |
| 合规审查 | 资质初筛、条款风险标注 | 高风险项最终裁决 |
| 技术方案 | 标准方案生成、POC 清单 | 复杂定制方案终审 |
| 收益结算 | 自动统计、生成报表 | 大额提现审批 |
| 战略决策 | 数据支撑、方案建议 | 方向拍板 |
