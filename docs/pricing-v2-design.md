## 一、核心问题诊断

### 1.1 当前痛点

| # | 问题 | 影响 |
|---|------|------|
| 1 | **价格断层** ¥99→¥1500 跳涨15倍 | 大量用户在体验版后流失 |
| 2 | **产品割裂** Token/员工/网络各自为政 | 用户决策复杂，难以估算总成本 |
| 3 | **价值模糊** 套餐内 Token≈"免费"，单独买又贵 | 用户不清楚真实成本结构 |
| 4 | **升级无感** 创业版→出海版缺乏递进价值 | 高价值用户直接跳走或不升级 |
| 5 | **与 InkCore 无联动** OPC定价和创作者收益脱节 | 创作者没有动力生产内容 |

### 1.2 设计原则

1. **平滑梯度**：任意两个相邻套餐价差 ≤ 3 倍
2. **清晰价值**：每个套餐解决一个明确阶段的痛点
3. **自然流转**：用完 A 自然会需要 B，用完 B 自然会需要 C
4. **成本透明**：Token 成本始终一致，不因套餐不同而"忽高忽低"
5. **生态闭环**：OPC 是"工具箱"，InkCore 是"变现出口"

## 二、产品关联性重新设计

### 2.1 核心洞察：跨境电商卖家的成长路径

OPC 的核心客户是**跨境电商卖家**，他们的成长有清晰阶段：

```
【阶段0】观望期（未入驻）
  └─ 想了解：AI能帮我做什么？TikTok怎么做？
  └─ 需求：低门槛体验、免费课程

【阶段1】新手期（0-3月）
  └─ 痛点：不会做内容、不会选品、没有工具
  └─ 需求：AI生成内容、学习课程、基础工具

【阶段2】成长期（3-12月）
  └─ 痛点：内容量不够、效率低、需要稳定网络
  └─ 需求：批量生成、多员工协作、跨境网络

【阶段3】稳定期（12月+）
  └─ 痛点：团队管理、多账号运营、合规风险
  └─ 需求：全员工套件、专线网络、合规风控

【阶段4】扩张期（成熟期卖家）
  └─ 痛点：规模化内容生产、变现渠道单一
  └─ 需求：创作者生态、InkCore 上架变现
```

### 2.2 产品矩阵重新设计

**旧设计（割裂）**：
```
Token 套餐 ── 轻量/标准/企业/年付（纯AI调用）
员工套餐 ── 体验/创业/出海（纯员工订阅）
网络服务 ── 个人/专业/企业（纯网络通道）
数字仓库 ── 单独定价（纯内容批发）
```

**新设计（场景化）**：
```
【新手起步】→ 解决"从0到1"的内容生产
  └─ 产品：启航版（含AI工具+课程+少量内容）

【内容加速】→ 解决"从1到10"的批量生产
  └─ 产品：加速版（含多员工+更多Token+批量工具）

【团队运营】→ 解决"团队协作+多账号管理"
  └─ 产品：团队版（含全员工+专线+多账号隔离）

【规模扩张】→ 解决"规模化+变现"
  └─ 产品：旗舰版（含全功能+创作者生态+InkCore上架）

【按需补充】→ 灵活加餐
  └─ 产品：Token加油包、员工增购、带宽升级
```

## 三、价格均衡设计

### 3.1 套餐价格梯度（平滑递进）

| 套餐 | 月费 | 相比上一档 | 目标用户 | 解决痛点 |
|------|------|-----------|---------|---------|
| **免费体验** | ¥0 | — | 观望期用户 | 零门槛了解平台 |
| **启航版** | ¥199 | — | 新手期卖家 | 开始做内容 |
| **加速版** | ¥599 | +3.0x | 成长期卖家 | 批量做内容 |
| **团队版** | ¥1999 | +3.3x | 稳定期卖家 | 团队+网络+合规 |
| **旗舰版** | ¥4999 | +2.5x | 扩张期卖家 | 规模化+变现 |

**关键改进**：
- 相邻套餐价差控制在 2.5-3.3 倍（原来 15 倍）
- 每个档位都有明确的价值增量（不是简单的"加员工+加Token"）
- 免费体验档降低注册门槛，解决"不了解"的问题

### 3.2 套餐内容详解

#### 免费体验版（¥0/月）
```
目的：降低注册门槛，让用户体验价值

  - 5万Token/月（仅国内模型）
  - 基础课程1节（TikTok入门）
  - 数字产品仓库：不可购买，仅浏览
  - 任务大厅：仅浏览，不可接单/发布
  - 跨境网络：不可用

```

```
目的：让新手卖家"从0到1"做出第一条内容

### 3.3 三线定价均衡（Token / 员工 / 网络）

#### 核心原则：套餐内"基础额度成本价"，超出"按标准价"

| 项目 | 套餐内成本价 | 超出标准价 | 说明 |
|------|------------|-----------|------|
| **Token** | 统一¥0.0002/Token | 统一¥0.0003/Token | 套餐内外价差50%，引导买套餐 |
| **员工** | 统一¥100/月/角色 | 统一¥200/月/角色 | 套餐内半价，单独买全价 |
| **网络** | 按带宽成本 | 按标价 | 套餐内绑定，不单独售 |

#### 套餐内Token成本一致性

```
启航版：20万Token × ¥0.0002 = ¥40成本
加速版：80万Token × ¥0.0002 = ¥160成本
团队版：200万Token × ¥0.0002 = ¥400成本
旗舰版：500万Token × ¥0.0002 = ¥1000成本

→ 套餐内Token成本占套餐价格比例：20%-25%
→ 其余75%-80%用于：员工+网络+课程+服务
```

#### 单独购买价格（用于套餐外增购）

| 增购项目 | 价格 | 说明 |
|---------|------|------|
| Token加油包 | ¥99/50万Token | 有效期内用完即止 |
| 员工增购 | ¥200/月/角色 | 任何角色统一价 |
| 带宽升级 | 每+5M = ¥300/月 | 从当前套餐基础升级 |
| 专属IP | ¥299/月/个 | 跨境电商防关联必备 |

### 3.4 跨境网络定价统一

**问题**：当前网络定价口径混乱（199/899/3999 vs 300元/M）

**统一方案**：

```
【共享带宽】（多用户共享出口，适合一般用途）
  5M  = ¥300/月（体验价¥199/首月）
  10M = ¥600/月
  20M = ¥1200/月

【独享带宽】（专属通道，适合跨境电商）
  10M = ¥1500/月（含1个专属IP）
  20M = ¥3000/月（含2个专属IP）
  50M = ¥7500/月（含5个专属IP）
  100M= ¥15000/月（含10个专属IP）

【套餐内包含】
  启航版：共享5M体验1个月（之后需单独购买或升级套餐）
  加速版：共享10M（长期）
  团队版：独享20M+1个专属IP（长期）
  旗舰版：独享50M+5个专属IP（长期）
```

**关键调整**：
- 套餐内网络是"绑定优惠"，不是"免费"
- 单独购买网络必须付全价，体现套餐价值
- 共享/独享明确区分，避免用户混淆

## 四、与 InkCore 联动定价

### 4.1 创作者等级与 InkCore 收益挂钩

| OPC 套餐 | 创作者等级 | InkCore 分成 | 说明 |
|---------|-----------|-------------|------|
| 免费体验 | 不可开通 | — | 无创作者权限 |
| 启航版 | 不可开通 | — | 仅消费者，不能上架 |
| 加速版 | 新手创作者 | 50% | 可上架，基础分成 |
| 团队版 | 认证创作者 | 60% | 通过认证，提高分成 |
| 旗舰版 | 金牌创作者 | 70% | 高质量创作者，最高分成 |
| 旗舰版（连续6月） | 合伙人创作者 | 80% | 长期合作，最高分成 |

### 4.2 上架费用与流量扶持

```
【上架费用】
  - 数字产品上架：免费（鼓励创作）
  - 特色推荐位：¥99/周（首页曝光）
  - 品类置顶：¥299/周（分类页置顶）

【流量扶持】
  - 新手创作者：前3个商品免费推荐位1周
  - 认证创作者：每月1个免费推荐位
  - 金牌创作者：每月3个免费推荐位+邮件推送
  - 合伙人创作者：首页轮播+社媒推广
```

### 4.3 收益回流定价

```
【结算周期】
  - 订单完成（7天自动确认）
  - 每月15日结算上月收益
  - 提现手续费：1%（最低¥1，最高¥100）

【汇率处理】
  - InkCore 售价：SGD
  - 回流到 OPC：按结算日汇率换算 CNY
  - 汇率波动风险：平台承担（定价时已包含2%汇率缓冲）
```

### 定价核心公式

```
套餐价格 = 员工成本 + Token成本 + 网络成本 + 服务溢价

  Token成本 = Token数 × ¥0.0002（套餐内）/ ¥0.0003（套餐外）
  网络成本 = 按带宽实际成本
  服务溢价 = 课程+客服+合规+创作者权益（边际成本低）

目标：团队版微利（绑定长期），旗舰版盈利（24%毛利）
      启航/加速战略性亏损（获客+培养）
