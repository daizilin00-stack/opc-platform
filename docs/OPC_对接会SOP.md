# OPC中心数字化服务平台 —— 需求对接会活动SOP

---

## 一、活动概述

| 项目 | 说明 |
|------|------|
| **活动名称** | OPC中新数字化需求对接会（第__期） |
| **活动目的** | 让发包方面对面发布需求，让服务商现场接单，撮合成交 |
| **活动频次** | 每月1场（重庆线下）+ 每两月1场（新加坡线上） |
| **参与规模** | 发包方 3-5家，服务商 15-30家，平台工作人员 2-3人 |
| **活动时长** | 2-2.5小时 |
| **场地类型** | 借用合作孵化器/园区会议室（免费），或线上腾讯会议/Zoom |

---

## 二、会前准备（活动前7-14天）

### 阶段1：锁定需求（T-14天）

| 动作 | 负责人 | 产出 |
|------|--------|------|
| 联系政府/国企/新加坡合作方，确认可公开发布的需求 | 平台BD | 《本期需求清单》（至少3个有效需求） |
| 用《需求发布模板》引导发包方填写完整需求 | 平台运营 | 3-5份完整需求表 |
| 与发包方确认：预算是否已批准、决策人是否出席、是否接受现场签约意向 | 平台BD | 发包方出席确认函 |

**本期需求清单标准**：
- 预算范围明确（哪怕区间）
- 交付周期在3个月内优先（便于快速成交）
- 至少1个需求适合「认证服务商」以上承接（有案例背书）
- 至少1个需求适合「见习服务商」练手（门槛低、金额小）

### 阶段2：招募服务商（T-10天）

| 动作 | 负责人 | 产出 |
|------|--------|------|
| 根据需求定向筛选平台入驻服务商，推送邀约 | 平台运营 | 邀约名单30家 |
| 在创业者社群、LinkedIn、朋友圈发布活动预告 | 平台运营 | 海报+文案 |
| 电话/微信重点邀请高匹配度服务商 | 平台BD | 确认出席15-20家 |
| 提醒参与者准备：名片/微信二维码、案例简述（1分钟版） | 平台运营 | 参会须知 |

### 阶段3：场地与物料（T-7天）

| 动作 | 负责人 | 产出 |
|------|--------|------|
| 与合作场地方确认日期、会议室、投影、网络 | 平台运营 | 场地确认 |
| 准备物料：易拉宝（OPC品牌）、签到表、名片盒、需求手册打印 | 平台运营 | 物料清单 |
| 准备线上会议室（如为线上活动）：测试Zoom/腾讯会议、准备虚拟背景 | 平台运营 | 会议链接 |

**零成本物料替代方案**：
- 易拉宝 → 用场地现有电视/投影播放PPT封面
- 打印手册 → 微信群发PDF版《本期需求手册》
- 名片盒 → 建活动专属微信群，扫码入群即交换电子名片

## 三、活动流程（2.5小时标准版）

### 上半场：需求发布（60分钟）

| 时间 | 环节 | 内容 | 负责人 |
|------|------|------|--------|
| 0:00-0:05 | 签到入群 | 扫码入活动群、发放电子需求手册 | 平台运营 |
| 0:05-0:10 | 开场破冰 | 主持人介绍OPC平台、本次活动规则、到场发包方 | 主持人 |
| 0:10-0:15 | 平台价值 | 5分钟讲清「为什么找OPC接单/发包」 | 平台负责人 |
| 0:15-0:45 | **需求发布** | 每家发包方8-10分钟：痛点+需求+预算+联系方式 | 发包方 |
| 0:45-0:50 | 中场休息 | 自由交流、加微信、看手册 | — |

**发包方演讲框架（提前发给发包方）**：
```
1. 我是谁（单位、行业、规模） —— 1分钟
2. 我遇到了什么痛点 —— 2分钟
3. 我需要什么（功能/交付物） —— 3分钟
4. 我的预算和时间 —— 1分钟
5. 我希望服务商有什么能力 —— 1分钟
6. 我的联系方式 —— 30秒
```

### 下半场：自由对接+意向撮合（60分钟）

| 时间 | 环节 | 内容 | 负责人 |
|------|------|------|--------|
| 0:50-1:20 | **自由对接** | 服务商主动找感兴趣的发包方1对1聊，平台人员巡场牵线 | 全体 |
| 1:20-1:35 | **意向登记** | 有明确意向的双方，到平台工作人员处登记「意向单」 | 平台运营 |
| 1:35-1:45 | **现场撮合** | 平台公布本场「意向匹配成功」名单，鼓掌见证 | 主持人 |
| 1:45-1:50 | **政策彩蛋** | 如有政府代表出席，简要介绍中小企业扶持政策（可选） | 嘉宾 |
| 1:50-2:00 | 结束合影 | 全体合影（用于后续宣传），预告下期活动 | 平台运营 |

**意向单登记内容**：
- 发包方名称 + 需求编号
- 服务商名称 + 联系人
- 意向金额区间
- 下一步动作（如：周三前提交方案、周五前安排实地拜访）
- 平台跟进人

### 线上版调整

| 调整项 | 线下版 | 线上版 |
|--------|--------|--------|
| 签到 | 扫码入群 | 入群+改名片（单位-姓名） |
| 需求发布 | 发包方上台 | 发包方共享屏幕PPT演讲 |
| 自由对接 | 走动1对1 | 分组讨论室（Breakout Rooms），每组1个发包方+3-5个服务商 |
| 意向登记 | 纸质登记表 | 群内接龙/在线表单 |
| 合影 | 现场拍照 | 截屏云合影 |

## 四、会后跟进（活动结束后7天内）

### Day 1：当天

| 动作 | 时间 | 负责人 |
|------|------|--------|
| 在活动群发布「今日意向匹配名单」 | 活动当晚 | 平台运营 |
| 发布活动照片/云合影到朋友圈、公众号 | 活动当晚 | 平台运营 |
| 给所有发包方发短信/微信：感谢出席，提醒查看群内服务商对接请求 | 活动当晚 | 平台BD |

### Day 2-3：撮合

| 动作 | 时间 | 负责人 |
|------|------|--------|
| 给所有登记「意向单」的双方单独拉小群 | Day 2 | 平台运营 |
| 在小群内推动：确定下一步（看场地/提方案/视频会） | Day 2-3 | 平台BD |
| 对未匹配成功的服务商：推送本期其他需求或下期预告 | Day 3 | 平台运营 |

### Day 7：结案

| 动作 | 时间 | 负责人 |
|------|------|--------|
| 统计本期成果：意向单__个、进入方案阶段__个、签约__个 | Day 7 | 平台运营 |
| 发布《OPC第__期对接会战报》（用于宣传及向政府汇报） | Day 7 | 平台运营 |
| 对已签约项目：启动平台撮合流程，签署三方合同 | 持续 | 平台BD |

## 六、常见问题应对

| 问题 | 应对话术 |
|------|---------|
| 发包方：「我能不能私下直接跟服务商谈？」 | 「建议通过平台走单，平台提供合同模板、过程管控、收款保障。如果一定私单，请您理解平台无法提供后续服务支持。」 |
| 服务商：「现场人太多，我没聊上发包方」 | 「我们已为您单独拉群，您现在可以直接加发包方微信。我帮您引荐。」 |
| 发包方：「预算还没批，先来了解一下」 | 「没问题，本场先建立联系。预算下来后平台优先推送匹配服务商。」 |
| 服务商：「我是见习，能接这个单吗？」 | 「这个需求需要认证以上。但建议您先接见习单练手，升认证后我优先推给您。」 |
| 到场人数不足 | 改为「精品闭门会」，强调小班深度对接的价值；或改期并加大定向邀约力度 |
