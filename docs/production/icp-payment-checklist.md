### 2.4 OPC 后端接入支付接口

**微信支付接入点：**
- 统一下单：`POST https://api.mch.weixin.qq.com/v3/pay/transactions/native`
- 回调地址：`https://csdp-agentwork.com/api/payment/wechat/callback`
- 需要：mch_id、API v3 密钥、API 证书、app_id

**支付宝接入点：**
- 统一下单：支付宝 SDK `AlipayClient`
- 回调地址：`https://csdp-agentwork.com/api/payment/alipay/callback`
- 需要：APPID、应用私钥、支付宝公钥、网关

**OPC 需要新增的后端模块：**
- `backend/src/routes/payment.js` 或 `payment.routes.js`
- `backend/src/services/payment.js`（微信/支付宝 SDK 封装）
- `backend/src/models/order.js`（订单模型）
- `backend/src/models/transaction.js`（交易流水）
- 数据库表：`orders`、`transactions`、`wallets`、`wallet_transactions`

### 2.5 前端支付页面

- `/recharge` 充值页面（选择金额 → 选择支付方式 → 调起支付）
- 支付结果页 `/payment/result?order_id=xxx`
