# OPC中心数字化服务平台 —— 服务商「业务护照」等级评定标准

---

## 一、等级体系总览

| 等级 | 标志 | 定位 | 可接订单类型 | 平台支持 |
|------|------|------|-------------|---------|
| 🥉 见习服务商 | BRONZE | 新手试炼 | 1万元以下练手单 | 培训、模板、导师1对1 |
| 🥈 认证服务商 | SILVER | 稳定交付 | 10万元以下政府/企业单 | 优先推荐、合同辅助、品牌背书 |
| 🥇 金牌合伙人 | GOLD | 核心力量 | 中新项目、新加坡需求、50万以下大单 | 联合投标、专属客户经理、提前锁单 |
| 💎 战略供应商 | PLATINUM | 生态共建 | 独家大单、年度框架协议 | 战略协同、共建实验室、资源倾斜 |

## 二、各等级评定标准

### 🥉 见习服务商（Bronze）

**准入条件（满足全部）**：
- [ ] 提交完整入驻申请表，资料真实
- [ ] 通过平台基础技能审核（技术方向匹配）
- [ ] 承诺接受平台规则，签署服务协议
- [ ] 无重大商业失信记录（平台征信核查）

**权利**：
- 可见并申请「见习单」（1万元以下、技术要求明确、交付周期短的练手项目）
- 参加平台组织的免费培训（需求沟通、合同签署、交付管理等）
- 获得平台标准合同模板、项目管理模板

**限制**：
- 不可申请政府/国企项目（除非项目明确标注「见习可接」）
- 不可申请新加坡需求
- 同一时段最多承接2个见习单

**升级条件（满足任意2条即可申请）**：
- 完成3个见习单，且客户好评率 ≥ 90%
- 累计见习单成交金额 ≥ 2万元
- 通过平台「认证服务商」技能测试
- 获得平台导师推荐信

---

### 🥈 认证服务商（Silver）

**准入条件（满足全部）**：
- [ ] 见习期满或满足见习升级条件
- [ ] 完成至少3个平台撮合项目
- [ ] 客户好评率 ≥ 90%（满分5分，平均分 ≥ 4.5）
- [ ] 无逾期交付记录（如有，逾期天数不超过约定工期10%）
- [ ] 无绕过平台私单记录

**权利**：
- 可见并申请「认证单」（10万元以下政府/国企/企业数字化项目）
- 在平台对外宣传案例中被署名
- 获得「认证服务商」电子/实体铭牌（可用于自身商务拓展）
- 优先被推荐给新入驻的发包方
- 可参加平台组织的「政府需求闭门会」

**义务**：
- 每周提交项目进度周报（如承接平台项目）
- 响应平台需求推送：24小时内确认是否接单
- 接受平台季度回访与等级复审

**升级条件（满足任意2条）**：
- 完成至少10个平台撮合项目
- 累计平台撮合成交金额 ≥ 50万元
- 完成至少1个中新相关项目或跨境项目
- 获得甲方书面表扬信/续约意向 ≥ 2份
- 主动为平台引荐优质发包方或服务商（成功入驻/成交）

**降级触发条件（满足任意1条即降级）**：
- 客户差评率 ≥ 20%（或出现1次严重差评）
- 无故逾期交付超过约定工期30%
- 被甲方/平台确认存在绕过平台私单行为
- 连续6个月未承接任何平台项目且未说明原因

---

### 🥇 金牌合伙人（Gold）

**准入条件（满足全部）**：
- [ ] 认证期满或满足认证升级条件
- [ ] 完成至少10个平台撮合项目
- [ ] 累计平台撮合成交金额 ≥ 100万元
- [ ] 客户好评率 ≥ 95%
- [ ] 有至少1个完整交付的成功案例可供平台宣传
- [ ] 团队规模 ≥ 3人（或可提供稳定交付能力证明）

**权利**：
- 可见并申请「金牌单」（中新项目、新加坡需求、50万元以下大单）
- 与平台联合投标大型项目（平台提供商务支持、品牌背书）
- 获得「金牌合伙人」专属标识及年度授牌
- 平台官网/公众号专属展示位
- 优先参与平台组织的「新加坡需求线上发布会」
- 享受平台「合规快车道」优先服务（数据跨境评估等）
- 年度免费使用平台合作云资源额度（如¥5000/年）

**义务**：
- 每季度至少承接1个平台项目（或说明合理原因）
- 参与平台组织的经验分享/培训授课（每年至少1次）
- 主动反馈行业动态及客户需求，协助平台优化服务
- 配合平台案例包装及媒体采访

**升级条件（满足任意2条）**：
- 累计平台撮合成交金额 ≥ 500万元
- 完成至少3个中新跨境项目
- 与甲方签订年度框架协议并通过平台履约
- 引入/孵化下游合作伙伴（ subcontractors ）并通过平台管理
- 为平台带来可量化的战略价值（如引入新加坡合作方、重大政府合作）

**降级触发条件**：
- 降级为认证服务商：连续2个季度未达金牌义务要求
- 直接降为见习：出现严重违约、商业欺诈、法律纠纷

---

### 💎 战略供应商（Platinum）

**准入条件**：
- [ ] 平台邀请制（不开放自主申请）
- [ ] 在某一垂直领域有深厚积累（如：只做法务数字化、只做跨境支付）
- [ ] 累计平台撮合成交金额 ≥ 500万元
- [ ] 客户续约率 ≥ 60% 或 获得甲方「年度优秀供应商」称号
- [ ] 有意愿与平台共建行业解决方案/联合实验室

**权利**：
- 享受「战略供应商」全部特权
- 平台为其定向「锁单」：在需求发布前，优先定向邀请其参与
- 共建「OPC-XX行业联合解决方案」，联合品牌输出
- 参与平台战略决策建议（如年度需求方向、政策建议）
- 年度商务费用减免或返还（如撮合服务费降至__%）
- 平台高管1对1服务及新加坡资源优先对接

**义务**：
- 与平台签订年度战略合作协议
- 承诺年度通过平台成交金额 ≥ __万元
- 共建行业标杆案例，配合平台重大宣传活动
- 协助平台审核新入驻服务商（导师/评审角色）

## 三、评定流程

```
申请/自动触发 → 材料提交 → 平台审核 → 结果通知 → 公示/授牌
```

| 环节 | 时间 | 说明 |
|------|------|------|
| 申请/触发 | 随时 | 自主申请，或平台根据数据自动触发升级提醒 |
| 材料提交 | 5个工作日 | 提交升级所需案例、证明、评分 |
| 平台审核 | 7个工作日 | 运营团队审核+技术顾问评估+甲方回访（抽查） |
| 结果通知 | 即时 | 邮件+微信通知，说明通过/不通过及原因 |
| 公示/授牌 | 次月 | 在平台公众号/官网公示，举办月度授牌仪式 |

## 四、动态升降级机制

### 4.1 升级
- 可随时满足条件即申请，无次数限制
- 升级后权益即时生效（除需要物理制作的铭牌/证书外）

### 4.2 降级
- **预警**：触发降级条件时，平台先发「黄牌预警」，给予30天整改期
- **正式降级**：整改期内未改善，执行降级，权益即时调整
- **申诉**：降级后15天内可提交申诉材料，平台15天内复核

### 4.3 清退
以下情况直接清退，不可恢复：
- 商业欺诈、伪造案例、冒用他人作品
- 严重泄露甲方商业秘密或数据
- 绕过平台私单且金额巨大、态度恶劣
- 被司法机关认定违法犯罪

## 五、评分维度（甲方评价表）

每个项目验收后，甲方从以下维度评分（1-5分）：

| 维度 | 权重 | 说明 |
|------|------|------|
| 交付质量 | 30% | 是否符合需求规格、有无bug |
| 交付速度 | 25% | 是否按期、里程碑是否准时 |
| 沟通配合 | 20% | 响应速度、态度、配合度 |
| 性价比 | 15% | 价格与成果是否匹配 |
| 售后支持 | 10% | 是否积极处理质保期内问题 |

**好评**：总分 ≥ 4.0  
**中评**：3.0 ≤ 总分 < 4.0  
**差评**：总分 < 3.0
