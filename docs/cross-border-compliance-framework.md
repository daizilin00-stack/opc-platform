# 跨境专线接入合规框架建议（平台接入模式）

> 适用场景：个人/小企业用户通过 AgentWork 平台使用跨境 AI 模型服务
> 核心矛盾：硬件成本 vs 合规责任归属

---

## 一、两种接入模式的本质差异

| 维度 | 平台接入（SaaS） | 硬件接入（CPE/专线） |
|------|-----------------|---------------------|
| **数据路径** | 客户 → 平台 → 专线 → 海外模型 | 客户 → 自有设备 → 专线 → 海外模型 |
| **合规主体** | 平台统一承担 | 客户 + 平台共同承担 |
| **成本结构** | 低（共享平台资质） | 高（硬件+专线独享） |
| **适用对象** | 个人/初创企业 | 中大型/数据敏感企业 |
| **数据控制权** | 平台作为处理者 | 客户作为控制者 |
| **审计难度** | 平台集中审计 | 分散审计 |

---

## 二、平台接入模式的核心合规风险

### 风险 1：数据出境安全评估责任归属
**问题：** 客户通过平台访问海外模型，其业务数据（prompt + 返回内容）经平台出境。平台是否需为每个客户单独做安全评估？

**建议方案：**
- **平台做统一安全评估**：将"AI 模型调用数据"作为一个整体出境场景，向网信办申请安全评估或标准合同备案
- **客户签署委托协议**：明确客户委托平台作为数据处理受托方，代表其进行跨境数据传输
- **数据分类分级**：区分「一般业务数据」和「重要数据」。平台默认仅处理一般业务数据；如客户涉及重要数据（如地理信息、基因数据、金融核心数据），需单独评估并引导至硬件专线模式

### 风险 2：个人信息保护（PIPL）
**问题：** 客户可能通过平台处理含个人信息的数据（如客服场景下的用户姓名、电话、地址）。

**建议方案：**
- **签署个人信息出境标准合同（SCC）**：平台作为出境方，与客户（个人信息处理者）签署 SCC
- **技术措施：**
  - 数据最小化：平台日志仅保留必要字段，不存储原始个人敏感信息
  - 脱敏处理：客服场景中，姓名、电话、身份证号等字段自动脱敏后再出境
  - 留存期限：交互日志保留 6 个月，到期自动清除
- **知情同意：** 平台在服务协议中明确告知客户「AI 数字员工服务涉及跨境数据传输」，客户签署合同即视为同意

### 风险 3：电信业务资质
**问题：** 平台提供跨境数据专线接入服务，是否需持有「国际数据通信业务经营许可证」？

**建议方案：**
- **依托中新数据港主牌照**：中新数据港重庆公司作为持牌方，平台作为其技术服务提供方（类似 ISP/IDC 牌照下的云服务模式）
- **合同条款：** 客户与中新数据港重庆公司签署《跨境数据服务协议》，平台仅提供软件界面和技术调度
- **收费主体：** 专线费用账单由中新数据港开具，平台仅收取软件服务费（SaaS 订阅 + Token 计费）

### 风险 4：内容安全与模型输出合规
**问题：** 海外模型（GPT/Claude）返回内容未经国内审查，可能含有敏感信息。

**建议方案：**
- **内容过滤层：** 在平台国内节点部署内容安全审核 API（如阿里云/腾讯云内容安全），对出境 prompt 和入境 completion 进行双向过滤
- **关键词拦截：** 建立敏感词库，涉及政治、色情、暴恐等内容的请求直接拦截，不传输至海外模型
- **审计日志：** 所有跨境请求记录 request_id、用户ID、时间戳、模型名称、Token 量，留存 6 个月备查
- **责任隔离：** 服务协议明确「平台仅提供技术通道，不对海外模型输出内容的准确性、合规性负责」

3. **中新数据港（新加坡）↔ 海外模型商**：签署《API 采购与数据处理协议》（上游供应链层）+ 支付美元

## 四、对小企业的具体操作路径

### 方案 A：全托管平台接入（推荐）
**适用：** 无 IT 团队、无合规团队的初创企业、个人创业者

**流程：**
1. 客户在平台完成注册 + 实名认证 + 企业认证（**已有公司直接上传营业执照，无公司可由平台代办注册**）
2. 平台自动生成标准化《数据出境委托协议》，客户电子签署
3. **平台统一采购海外模型 API，客户无需自行注册 OpenAI/Claude 账号，无需外币信用卡**
4. 平台统一使用已备案的出境通道，客户无需单独申报
5. 客户的所有跨境数据请求均经平台内容过滤 + 审计日志记录
6. 客户可随时在「工作台 → 合规中心」查看自己的数据出境记录

**优势：**
- 客户零合规成本（无需请律师、无需做安全评估）
- 平台集中管控，风险可控
- 开园推广效率高，转化路径短

### 方案 B：半托管接入（可选升级）
**适用：** 有一定数据敏感度，但仍不想投入硬件的中型企业

**流程：**
1. 在方案 A 基础上，客户可申请「独立出境通道」
2. 平台为客户分配独立的虚拟通道标识（VLAN/子账号）
3. 客户可自行配置内容过滤规则（在平台提供的规则库中选择）
4. 审计日志单独归档，客户可导出

**优势：**
- 数据隔离度更高
- 满足部分企业的审计要求
- 仍无需硬件投入

### 方案 C：硬件专线接入（高敏感客户）
**适用：** 金融、医疗、政务等对数据主权要求极高的企业

**流程：**
1. 中新数据港为客户部署 CPE 设备（或客户自有设备接入）
2. 客户与中新数据港签署专线租用协议
3. 客户自行完成数据出境安全评估（或委托平台协助）
4. 数据不经过平台 SaaS 层，直连专线

**成本：** 设备押金 + 专线月租（10M/¥3,500 起）

## 五、合规管理的技术实现建议

### 1. 数据分类自动识别
```
客户上传/输入数据
    │
    ▼
┌─────────────────┐
│ 敏感数据识别引擎 │ ← 正则 + NLP 模型
│ - 身份证号       │
│ - 手机号         │
│ - 银行卡号       │
│ - 地理位置       │
│ - 企业核心数据   │
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
  一般数据   敏感数据
    │         │
    ▼         ▼
  正常出境   自动脱敏/提示客户升级至硬件模式
```

### 2. 审计日志系统（最小必要字段）
| 字段 | 说明 | 保留期限 |
|------|------|----------|
| request_id | 请求唯一标识 | 6 个月 |
| user_id | 用户标识（脱敏） | 6 个月 |
| timestamp | 时间戳 | 6 个月 |
| model_name | 模型名称 | 6 个月 |
| prompt_tokens | 输入 Token 量 | 6 个月 |
| completion_tokens | 输出 Token 量 | 6 个月 |
| **原始 prompt 内容** | ❌ **不存储** | — |
| **原始 completion 内容** | ❌ **仅存储前 50 字符摘要** | 6 个月 |
| content_risk_score | 内容安全风险评分 | 6 个月 |
| block_reason | 拦截原因（如有） | 6 个月 |

### 3. 内容安全过滤策略
- **白名单模式（默认）：** 仅允许业务相关请求出境（客服、销售话术、技术文档等）
- **黑名单模式：** 拦截涉及政治、色情、暴恐、赌博等内容的请求
- **敏感行业限制：** 涉及金融交易指令、医疗诊断建议等高风险场景，强制要求人工确认

## 六、商业模式与合规的协同

| 合规措施 | 商业收益 |
|---------|---------|
| 平台统一做安全评估 | 小企业获客成本降低，入园转化率提升 |
| 内容安全过滤 | 避免监管处罚风险，保护平台牌照 |
| 审计日志透明 | 增强客户信任，可作为「合规增值服务」卖点 |
| 数据脱敏 | 满足客户隐私顾虑，降低客诉 |
| 三级接入模式（平台/半托管/硬件） | 覆盖从个人到企业的全客单价带 |

## 七、CEO 建议的下一步行动

1. **法务层面：**
   - 委托律师起草《数据出境委托处理协议》模板
   - 确认中新数据港现有牌照是否覆盖「为第三方提供跨境数据通道服务」
   - 向网信办咨询：平台统一安全评估是否可覆盖旗下 SaaS 产品

2. **技术层面：**
   - 在平台国内节点部署内容安全审核 API（预算 ¥5,000-10,000/月）
   - 开发「合规中心」页面：展示客户的数据出境记录、审计日志下载
   - 实现敏感数据自动识别 + 脱敏（可使用开源组件 + 正则规则库）

3. **产品层面：**
   - 注册流程增加「数据出境告知」步骤（类似隐私政策勾选）
   - 工作台增加「合规看板」入口
   - 定价方案中明确「平台接入」vs「硬件接入」的适用场景

4. **市场层面：**
   - 将「合规跨境」作为核心卖点（区别于翻墙/VPN）
   - 制作《中新数据港跨境合规白皮书》作为获客资料

---

**结论：** 小企业全部走平台接入模式是完全可行的。关键在于：

1. **平台层面承担数据处理者角色**，通过统一合规框架（安全评估 + SCC + 内容过滤 + 审计日志）覆盖所有下游客户
2. **法规闭环：一人公司也是法人主体** — 按照通信服务规定，中新数据港向公司（含一人有限公司）提供服务不存在法规障碍，个人创业者通过平台注册公司后即可作为法人主体接受服务
3. **平台代理海外模型采购** — 国内客户无需自行注册 OpenAI/Claude 账号，无需外币信用卡；平台统一通过新加坡公司向海外模型商采购 API，国内客户只需向平台支付人民币即可使用海外模型能力
4. **这不仅不会增加客户负担，反而能成为平台的核心竞争壁垒**
