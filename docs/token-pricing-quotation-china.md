## 一、定价策略说明

### 1.1 成本结构

OPC 平台海外模型调用采用**双通道架构**，成本构成如下：

```
┌─────────────────────────────────────────────────────────────┐
│                    成本结构透明化                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【上游采购成本】Ling API 合作价（2.4折）                    │
│  ├─ 基础折扣：官方定价 × 0.24（月度 < 3000万 Token）       │
│  ├─ 进阶折扣：官方定价 × 0.23（月度 3000万-1亿 Token）     │
│  └─ 战略折扣：官方定价 × 0.20（月度 > 1亿 Token）          │
│                                                             │
│  【跨境传输成本】中新数据港专线                              │
│  ├─ 轻量通道：公网传输（无额外成本）                       │
│  ├─ 标准通道：专线分摊成本 ~¥0.5/千Token                   │
│  └─ 企业通道：独享专线 + 专属IP（成本较高）                 │
│                                                             │
│  【平台服务成本】                                          │
│  ├─ 统一网关、计费、审计系统                               │
│  ├─ 7×24 客服与技术支持                                   │
│  ├─ 合规报告与审计日志                                     │
│  └─ 平台运营与开发维护                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 三层定价逻辑

| 层级 | 目标客群 | 折扣率 | 毛利率 | 核心卖点 |
|------|---------|--------|--------|----------|
| **个人版** | 个人卖家、SOHO、开发者 | **6.5折** | 61.5% | 比官方便宜 35%，有平台管理 |
| **团队版** | 中小企业、跨境电商团队 | **5.5折** | 54.5% | 比官方便宜 45%，主力产品 |
| **企业版** | 大企业、政府、合规要求极高 | **8.0折** | 68.8% | 完全合规，官方账号，审计报告 |

**定价公式**：
```
售价 = 官方定价 × 折扣系数
成本 = 官方定价 × 0.24（Ling API 2.4折）
毛利 = 售价 - 成本 - 专线分摊
```
