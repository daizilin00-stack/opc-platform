## 一、服务概述

### 1.1 关于中新数据港 OPC 数字平台

中新数据港 OPC 数字平台依托**中新（重庆）战略性互联网数据专用通道**，为中国企业和个人创业者提供**合规、稳定、低延迟**的海外大模型 API 访问服务。

**我们的优势**：
- ✅ 中新数据港官方背书，跨境数据传输合规可控
- ✅ 统一 API 接口，兼容 OpenAI SDK，无需修改代码即可切换模型
- ✅ 支持 GPT-4o / Claude 3.5 / Gemini 1.5 / DeepSeek 等全系列主流模型
- ✅ 比官方价格低 35-55%，支持人民币付款，可开具发票
- ✅ 审计日志完整，满足企业合规审查要求
- ✅ 7×24 小时技术支持，99% 服务可用性保障

### 1.2 三种服务通道

| 通道 | 传输方式 | 合规性 | 适用场景 | 推荐用户 |
|------|---------|--------|---------|---------|
| **标准通道** | 中新数据港跨境专线 | **中高** | 日常业务、批量调用 | 中小企业、团队 |
| **企业通道** | 独享专线 + 官方账号 | **高** | 高合规要求、审计场景 | 大企业、金融机构 |
| **轻量通道** | 公网优化传输 | 一般 | 个人测试、非核心业务 | 个人开发者、SOHO |

> **默认推荐**：标准通道（团队版），性价比最优，合规性满足绝大多数企业需求。
