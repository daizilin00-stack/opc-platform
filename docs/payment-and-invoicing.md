## 二、收款方式与渠道

### 2.1 人民币收款（中国用户）

| 渠道 | 接入方式 | 到账时间 | 手续费 | 适用场景 |
|-----|---------|---------|-------|---------|
| **微信支付** | 微信商户号（企业认证） | T+1 | 0.6% | 个人用户小额充值、移动端 |
| **支付宝** | 支付宝企业商户 | T+1 | 0.6% | 个人用户小额充值、PC端 |
| **对公转账** | 用户转账至公司银行账户 | 实时（同行）/1-3工作日（跨行） | 无（用户承担） | 企业用户大额充值、月结 |
| **银行代扣** | 签约企业授权扣款 | 按协议 | 协商 | 企业月结客户 |

**资金流转路径：**
```
用户支付（微信/支付宝/银行）
    │
    ▼
第三方支付平台（微信商户/支付宝商户）
    │
    ▼ 自动结算 T+1
中新数据港重庆公司 — 对公银行账户
    │
    ▼ 平台自动分账
平台运营资金 / 供应商结算 / 税费预留
```

## 三、平台充值与支付流程

### 3.1 用户端充值流程

```
用户进入「工作台 → 钱包/充值」
    │
    ▼
选择充值金额 / 套餐
    │
    ▼
选择支付方式
├─ 微信支付（扫码/JSAPI）
├─ 支付宝（扫码/网页支付）
├─ 对公转账（显示公司银行账户信息）
├─ 国际信用卡（Stripe 卡支付）
└─ PayPal
    │
    ▼
支付完成 → 平台回调确认
    │
    ▼
钱包余额实时到账（微信/支付宝/Stripe即时）
或等待人工确认（对公转账需1-3天）
    │
    ▼
自动触发开票（如用户已填写开票信息）
或用户后续手动申请开票
```

### 3.2 自动支付 vs 人工支付

| 支付方式 | 到账方式 | 余额生效时间 | 是否需要人工审核 |
|---------|---------|------------|---------------|
| 微信支付 | 自动回调 | 即时 | 否 |
| 支付宝 | 自动回调 | 即时 | 否 |
| Stripe 卡支付 | 自动回调 | 即时 | 否（风控通过） |
| PayPal | 自动回调 | 即时 | 否（大额需审核） |
| 对公转账 | 用户上传凭证 | 财务确认后 | **是**（财务审核） |
| 银行电汇 | 用户上传凭证 | 财务确认后 | **是**（财务审核） |

## 四、开票流程设计

### 4.1 中国用户 — 增值税发票

**发票类型：**
- 增值税电子普通发票（默认，个人/小规模企业）
- 增值税专用发票（一般纳税人企业，需额外资质审核）

**开票信息收集：**
```
用户首次开票时填写：
├─ 发票类型（普票/专票）
├─ 发票抬头（公司名称）
├─ 统一社会信用代码
├─ 注册地址
├─ 开户银行及账号
├─ 联系电话
└─ 接收邮箱（电子发票发送）
```

**开票规则：**

| 场景 | 开票时机 | 发票内容 | 税率 |
|-----|---------|---------|------|
| 钱包充值 | 用户申请开票时 | *技术服务*（统一） | 6%（现代服务业） |
| 订阅套餐（硅基员工） | 支付完成后自动开票 | *技术服务*（统一） | 6% |
| Token 充值 | 按实际消耗开票 或 充值时全额开票 | *技术服务*（统一） | 6% |
| 网络服务（跨境专线） | 支付完成后自动开票 | *技术服务*（统一） | 6% |
| 企业定制开发 | 按合同里程碑开票 | *技术服务*（统一） | 6% |

**自动开票流程：**
```
用户支付完成
    │
    ▼
系统判断用户是否已填写开票信息
    │
    ├─ 已填写 → 自动开票（电子发票）→ 发送邮箱
    └─ 未填写 → 推送通知「请填写开票信息」→ 用户手动申请
    │
    ▼
电子发票系统（⏳ 待选定第三方服务商：百望/航天信息/高灯）
    │
    ▼
发票生成（PDF + OFD 格式）
    │
    ▼
邮件发送给用户
    │
    ▼
发票数据同步至税务系统（自动报税）
```

### 4.2 海外用户 — 新加坡 Invoice

**发票类型：**
- 新加坡 Tax Invoice（含 GST，如适用）
- 商业发票（Commercial Invoice，不含税）

**开票信息：**
```
├─ Company Name（公司名）
├─ Registration Number（新加坡 UEN / 海外公司注册号）
├─ Billing Address（账单地址）
├─ Contact Email
└─ 接收方式（Email PDF）
```

**GST 规则：**
- 新加坡 GST 税率：9%（2024 年起）
- 平台注册 GST 门槛：年营业额 > S$1,000,000
- 如未达门槛，Invoice 可不含 GST，但需注明 "GST not applicable"

**发票格式：**
```
中新数据港新加坡公司
Tax Invoice #INV-2026-0001
Date: 2026-06-02

Bill To:
[客户公司名]
[客户地址]

Items:
1. AI Digital Employee Subscription (Startup Plan)    USD 250.00
2. Network Service (Professional) - June 2026        USD 899.00
                                                        ─────────
Subtotal                                              USD 1,149.00
GST (9%)                                                USD 103.41
                                                        ─────────
Total                                                 USD 1,252.41

Payment Terms: Net 30
Bank: [新加坡银行账户]
```

## 七、退款与红冲流程

### 7.1 退款规则

| 场景 | 退款政策 | 处理时效 |
|-----|---------|---------|
| 钱包余额未使用 | 全额退款 | 3-5 工作日 |
| 订阅套餐未使用（7天内） | 全额退款 | 3-5 工作日 |
| 订阅套餐已部分使用 | 按剩余天数比例退款 | 3-5 工作日 |
| Token 已消耗 | 不可退款 | — |
| 网络服务已使用 | 按剩余天数比例退款 | 3-5 工作日 |
| 企业定制项目 | 按合同条款 | 协商 |

### 7.2 退款 + 发票红冲流程

```
用户申请退款
    │
    ▼
客服审核（符合退款规则）
    │
    ▼
财务执行退款（原路退回）
    │
    ├─ 微信/支付宝 → 原路退回用户账户
    ├─ 对公转账 → 退回原付款账户
    └─ Stripe/PayPal → 原路退回信用卡/账户
    │
    ▼
如已开票 → 系统自动发起「红冲发票」
    │
    ▼
通知用户：退款完成 + 红冲发票已发送
```

## 九、合规注意事项

### 9.1 税务合规

| 税种 | 适用场景 | 税率 | 缴纳主体 |
|-----|---------|------|---------|
| 增值税 | 中国用户收款 | 6% | 重庆公司 |
| 企业所得税 | 年度利润 | 25% | 重庆公司 |
| 新加坡 GST | 新加坡用户收款（年营收>S$1M） | 9% | 新加坡公司 |
| 新加坡企业所得税 | 年度利润 | 17% | 新加坡公司 |
| 预提税 | 向海外模型商支付API费用 | 10% | 视双边协定 |

### 9.2 资金合规

- **资金池隔离**：中国用户资金进入重庆公司账户，海外用户资金进入新加坡公司账户，不得混用
- **外汇管制**：新加坡公司外币资金如需汇入中国，需通过合法渠道（FDI/服务贸易）结汇
- **反洗钱**：单笔充值超过 ¥50,000 / $10,000 需触发 KYC 加强审核
