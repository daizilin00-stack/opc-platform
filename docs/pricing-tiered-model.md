## 四、用户升级路径

### 4.1 自然升级设计

```
【个人用户的成长路径】

阶段0：免费体验
  └─ 5万Token，体验平台
  └─ 7天内引导购买轻量包

阶段1：个人轻量
  └─ 10-50万Token/月
  └─ 当用量超过50万时，提示：
     "你的用量已达到团队标准，升级团队版享受5.5折更低价格"

阶段2：个人升级团队
  └─ 完成企业认证
  └─ 切换到团队版（5.5折），用量越大越划算
  └─ 解锁团队管理功能

阶段3：团队升级企业
  └─ 当需要合规报告时
  └─ 提示："升级到企业版，获得完全合规+审计报告"
  └─ 切换到企业版（8折），但获得合规保障

【升级激励机制】
  个人→团队：首次升级赠送50万Token（价值¥99）
  团队→企业：首次升级赠送1个月免费企业版体验
  连续3月消费>¥1000：自动升级团队版折扣（额外95折）
```

### 4.2 价格锚点设计

```
【让用户觉得团队版最划算】

个人版：GPT-4o Input = ¥0.0234/1K
团队版：GPT-4o Input = ¥0.0198/1K
企业版：GPT-4o Input = ¥0.0288/1K

锚点策略：
  1. 个人版比团队版贵18%（让用户想升级）
  2. 企业版比团队版贵45%（但合规保障值这个价）
  3. 团队版比官方便宜45%（最大性价比）
  4. 个人版比lingapi.com贵2.6倍（但买平台服务）

展示方式：
  "团队版比个人版省18%，比官方便宜45%"
  "企业版贵，但完全合规，适合有审计要求的企业"

    · 团队用户愿意付溢价

  企业版（8折）：
    · 比官方便宜20%，完全合规
    · 和lingapi.com无关，走官方账号
    · 企业用户只为合规买单

  结果：三类用户都找到适合自己的产品，LTV提升
```
