# OPC 新加坡数字商品平台（SG Digital Store）

> **代号：** SG-DStore  
> **定位：** 面向东南亚消费者的数字商品 C2C 交易平台  
> **核心场景：** TikTok卖家 → 发布数字商品链接 → 消费者点击购买 → 自动交付  
> **运营主体：** 中新数据港新加坡公司（CHINA-SINGAPORE DATA PORT PTE. LTD.）  
> **日期：** 2026-06-07  
> **版本：** v0.1

### 3.2 支付系统（Payment）

**支付渠道：**

| 渠道 | 适用场景 | 费率 | 结算周期 |
|------|----------|------|----------|
| **Stripe** | 信用卡/借记卡（国际） | 3.4% + S$0.50 | T+7 |
| **PayNow** | 新加坡本地银行转账 | 1% | T+1 |
| **GrabPay** | 东南亚电子钱包 | 2.5% | T+7 |
| **PayPal** | 国际买家 | 4.4% + 固定费 | T+1 |

**支付流程：**
```
消费者下单 → 选择支付方式 → 跳转支付网关 → 支付成功
    ↓
平台收到款项 → 冻结（escrow）→ 立即触发交付
    ↓
消费者确认收货/7天自动确认 → 资金释放给卖家（扣10-15%平台费）
```

**订单状态：**
- `pending_payment` — 待支付
- `paid` — 已支付，待交付
- `delivered` — 已交付
- `completed` — 已完成（7天自动确认或手动确认）
- `refunded` — 已退款
- `disputed` — 争议中

### 3.3 自动交付系统（Delivery）

**交付方式：**

| 方式 | 适用商品 | 技术实现 |
|------|----------|----------|
| **下载链接** | 文件类（PDF/视频/模板） | 生成临时URL（24小时有效） |
| **邮箱发送** | 所有数字商品 | 支付成功后自动发送邮件 |
| **页面内下载** | 所有数字商品 | 订单详情页显示下载按钮 |
| **API密钥** | 工具/软件 | 生成唯一授权码 |
| **Notion链接** | Notion模板 | 分享链接自动发送 |
| **网盘链接** | 大文件 | 预签名URL |

**交付流程：**
```
支付成功 Webhook → 订单状态更新为 "delivered"
    ↓
├─ 生成下载页面（含临时token）
├─ 发送邮件（订单确认 + 下载链接）
├─ 发送站内通知
└─ 记录交付日志
```

**下载页面：**
- URL格式：`https://store.csdport.sg/download/{order_id}?token={jwt}`
- Token有效期：24小时（可重复下载）
- 过期后：登录订单页面重新生成

### 3.4 卖家后台（Seller Dashboard）

**核心功能：**

| 模块 | 功能 |
|------|------|
| **商品管理** | 上传/编辑/上下架/删除/批量操作 |
| **订单管理** | 查看订单/处理退款/导出报表 |
| **收入统计** | 销售额/订单量/退款率/趋势图表 |
| **店铺设置** | 店铺名称/头像/简介/横幅/自定义域名 |
| **营销工具** | 优惠券/限时折扣/捆绑销售 |
| **评价管理** | 查看评价/回复评价/申诉差评 |
| **提现管理** | 申请提现/绑定银行账户/查看记录 |

**商品上传流程：**
```
卖家 → 上传文件 → 填写信息（标题/描述/价格/分类）
    → 上传预览图（3-5张）
    → 设置标签/关键词
    → 提交审核（自动/人工）
    → 上架销售
```

**卖家等级体系：**

| 等级 | 要求 | 权益 |
|------|------|------|
| **新手** | 注册即可 | 上传10个商品，平台抽15% |
| **认证卖家** | 完成10单 + 好评率>90% | 上传50个商品，抽12% |
| **金牌卖家** | 完成100单 + 好评率>95% | 无限上传，抽10%，首页推荐 |
| **合伙人** | 月销>S$5000 | 抽8%，专属客服，优先审核 |

## 五、与OPC主平台的关联

### 5.1 账号体系

```
OPC 主平台（创业者账号）          SG Digital Store（卖家账号）
    │                                   │
    │  单点登录（SSO）                   │
    │  同一套账号体系                     │
    ▼                                   ▼
┌──────────────────────────────────────────┐
│  一个账号，两个角色                         │
│  · 在OPC：创业者/卖家（接任务/发布任务）     │
│  · 在SG Store：数字商品卖家（上架商品）      │
│  · 钱包共用：Token余额 + SGD余额            │
│  · 信誉共用：信用分/好评率跨平台同步         │
└──────────────────────────────────────────┘
```

### 5.2 商品来源

**OPC 数字产品仓库 → SG Digital Store：**

```
OPC 创作者生产内容 → 进入数字产品仓库（B2B批发）
    │
    ├─ 创作者选择 "同时在SG Store零售" → 一键上架
    │
    ▼
SG Digital Store（C2C零售）
    · 价格：零售价（高于批发价）
    · 交付：自动交付系统
    · 分成：创作者70% + 平台10% + SG Store 15%（含税/支付成本）
```

### 5.3 数据同步

| 数据 | 同步方向 | 说明 |
|------|----------|------|
| 用户账号 | OPC ↔ SG Store | 注册一次，双平台通用 |
| 钱包余额 | OPC ↔ SG Store | SGD余额共用，Token独立 |
| 卖家信誉 | OPC → SG Store | 好评率/信用分跨平台同步 |
| 商品数据 | OPC仓库 → SG Store | 创作者选择同步上架 |
| 交易数据 | SG Store → OPC | 销售统计汇入OPC收益中心 |
| 数字员工 | OPC → SG Store | 卖家可用AI数字员工优化商品 |

## 六、商业模式

### 6.1 收入结构

| 收入项 | 比例 | 说明 |
|--------|------|------|
| **平台交易佣金** | 10-15% | 按卖家等级阶梯 |
| **支付通道费** | 实际成本 | Stripe/PayNow等手续费，向卖家实收 |
| **推广位收费** | 固定费用 | 首页推荐位/分类置顶 |
| **会员订阅** | 月费 | 卖家高级会员（更多功能/更低佣金） |
| **增值服务** | 按次收费 | 加急审核/数据分析/营销工具 |

### 6.2 定价策略

**商品定价建议：**

| 商品类型 | 建议零售价（SGD） | 创作者成本（OPC批发） | 毛利率 |
|----------|------------------|----------------------|--------|
| 短视频脚本（10条） | S$5-15 | S$3-8 | 40-50% |
| 设计模板（1套） | S$10-30 | S$5-15 | 50% |
| 视频素材（1条） | S$15-50 | S$8-25 | 40-50% |
| 直播脚本（1场） | S$20-50 | S$10-25 | 50% |
| 选品报告（1份） | S$50-150 | S$25-75 | 50% |
| 课程/教程 | S$50-300 | - | 创作者自定 |
| 工具/软件 | S$20-100 | - | 创作者自定 |

**平台佣金：**
- 新手卖家：15%
- 认证卖家：12%
- 金牌卖家：10%
- 合伙人：8%

### 6.3 创作者分成

```
消费者支付 S$100
    │
    ├─ 支付通道费：S$3.4（Stripe 3.4%）
    │
    ├─ 平台佣金：S$12（认证卖家12%）
    │
    ├─ 创作者收入：S$70（70%）
    │
    └─ SG Store 平台：S$14.6（剩余，覆盖运营+交付成本）
```

## 八、技术实现要点

### 8.1 文件存储与CDN

```
数字文件上传 → AWS S3 Singapore (ap-southeast-1)
    │
    ├─ 原始文件：S3 Standard存储
    ├─ 缩略图：自动生成 300x300/600x600
    └─ 预览图：压缩优化
    │
    ▼
CloudFront CDN (新加坡边缘节点)
    · 全球加速下载
    · 带宽成本控制
    · 防盗链（Referer + Token验证）
```

### 8.2 防盗链与下载控制

- **临时Token**：下载URL含24小时有效期的JWT
- **IP绑定**：可选绑定购买时IP地址
- **次数限制**：每个订单最多下载10次
- **Referer检查**：防止直接分享下载链接

### 8.3 支付Webhook安全

```
Stripe Webhook → 验证签名 → 更新订单状态 → 触发交付
    │
    ├─ 幂等处理：相同event_id只处理一次
    ├─ 失败重试：自动重试3次
    └─ 日志记录：完整支付链路审计
```
