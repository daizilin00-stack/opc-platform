# 致 LingAPI 商务确认函（草案）

**发件方**：中新数据港（重庆）科技有限公司（以下简称"CSDP" / "OPC"）
**收件方**：LingAPI（联调环境运营方）
**事由**：关于 OPC 平台与 LingAPI 渠道合作模式的商务确认

---

尊敬的 LingAPI 合作伙伴：

感谢贵方在模型渠道方面给予 CSDP OPC 项目的支持。随着 OPC 平台即将正式开园运营，为明确双方权责、保障合作长期稳定，现就双方合作模式确认如下核心条款，请贵方书面确认。

## 一、结算关系

1. **CSDP 作为唯一结算主体**：OPC 平台所有终端客户产生的模型调用费用，统一由 CSDP 与 LingAPI 按双方约定的批发价格进行结算。LingAPI **不向 OPC 终端客户直接开具账单、收取费用或建立结算关系**。

2. **CSDP 自有计费体系**：OPC 平台拥有独立的客户计费系统，按 CSDP 自有价格向终端客户收取模型调用费用。LingAPI 仅需向 CSDP 提供清晰、可核对的总体用量账单。

3. **账期与对账**：建议按月对账，LingAPI 应于每月 5 日前向 CSDP 提供上月总用量明细及金额，CSDP 在收到账单后 10 个工作日内完成确认并安排付款。

## 二、客户归属保护

1. **客户归 CSDP 所有**：OPC 平台注册客户、企业客户及其联系方式、用量数据等商业信息归 CSDP 所有。

2. **禁止越过 CSDP 接触客户**：LingAPI 及其关联方**不得**以任何方式直接接触、营销、报价或向 OPC 终端客户提供服务，包括但不限于：
   - 向 OPC 客户发送 LingAPI 品牌登录链接、价格表、推广材料；
   - 以"更便宜""直接合作"等理由劝说 OPC 客户转投 LingAPI；
   - 向 OPC 客户提供技术支持时要求客户绕过 CSDP。

3. **违约处理**：如 LingAPI 违反客户归属保护条款，CSDP 有权暂停结算、终止合作，并保留追究违约责任的权利。

## 三、价格与品牌隔离

1. **批发价格保护**：LingAPI 向 CSDP 提供的采购价格应低于 LingAPI 对外公开零售价格，以保证 CSDP 拥有合理的运营与服务空间。若公开价即为合作价，CSDP 将不得不把模型作为引流品，利润从合规专线、数字员工订阅与增值服务中取得，这将限制双方在模型用量上的共同增长空间。

2. **品牌隔离**：LingAPI 在响应 OPC 平台请求时，应避免在 HTTP 响应头、错误类型、日志或任何返回内容中暴露 LingAPI 品牌信息（如 `X-New-Api-Version`、`new_api_error` 等），以保障 OPC 品牌独立性。

3. **数据保密**：LingAPI 不得留存、分析或利用 OPC 终端客户的提示词内容、对话数据、用量明细等敏感信息用于商业目的。

## 四、合作定位

CSDP OPC 不是 LingAPI 的二级分销渠道。双方是**平台方与上游供应商**的合作关系：
- CSDP 负责客户开发、品牌运营、合规服务、账单结算与技术支持；
- LingAPI 负责提供稳定、优质的模型 API 能力。

双方共同努力，让客户认可 CSDP/OPC 的服务价值，而非让客户直接接触上游渠道。
