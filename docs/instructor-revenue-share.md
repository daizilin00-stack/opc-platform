# 培训学院讲师入驻、定价与分润方案

> 状态：方案设计稿，待董事长/产品确认后进入开发。

---

## 1. 讲师入驻流程

```
申请入口：培训学院底部「联系平台运营」→ 打开客服浮窗 / 提交申请表单
        ↓
平台运营审核（3 个工作日内）
        ↓
签署《讲师入驻协议》（电子签）
        ↓
开通讲师后台
        ↓
上传课程 → 平台审核 → 上架销售
```

### 1.1 入驻条件
- 在跨境电商、AI 应用、数据合规、出海运营等领域有 2 年以上实战经验；
- 能独立产出系统化课程内容（视频/图文/课件）；
- 同意平台定价与分润规则；
- 个人/企业身份均可入驻，企业需开具发票。

### 1.2 入驻入口改造
- 当前培训学院底部「联系平台运营」按钮登录后跳转 `/workspace`（已修复为打开客服对话框）。
- 后续改为：点击后打开「讲师入驻申请表单」弹窗或跳转 `/courses/instructor/apply`，填写：姓名、手机号、擅长领域、课程方向、样章/简历上传。

## 2. 课程定价模式

### 2.1 统一定价（开园阶段建议）
| 档位 | 价格 | 适合内容 |
|------|------|----------|
| 免费课 | ¥0 | 引流、品牌曝光、新手入门 |
| 入门课 | ¥99-299 | 单点技能、工具使用、案例拆解 |
| 进阶课 | ¥299-999 | 系统方法论、实战项目、合规专题 |
| 高阶课/私教 | ¥1999+ | 1v1 陪跑、企业内训、认证培训 |

### 2.2 讲师自主定价（成熟期开放）
- 讲师在后台提交建议价；
- 平台基于同类课程均价、讲师等级、内容质量给出建议折扣；
- 最终价格由平台审核后生效，避免低价倾销或定价虚高。

### 2.3 促销与会员
- 平台可针对课程发放优惠券，成本由平台承担；
- 会员订阅制（如 ¥299/年 学习会员）：平台按播放量/完课率向讲师结算。

## 3. 分润模式

### 3.1 标准分润（推荐）
| 角色 | 比例 | 说明 |
|------|------|------|
| 讲师 | 60% | 内容创作与交付 |
| 平台 | 30% | 流量、支付、审核、客服、基础设施 |
| 推广佣金 | 10% | 分销/推荐奖励（可选） |

示例：一门 ¥599 课程售出 1 份，讲师到账 ¥359.4。

### 3.2 阶梯分润（激励头部讲师）
| 月销售额 | 讲师分成比例 | 平台比例 |
|----------|--------------|----------|
| ≤ ¥5000 | 60% | 40%（含推广池 10%）|
| ¥5000-¥20000 | 65% | 35% |
| ¥20000-¥50000 | 70% | 30% |
| > ¥50000 | 75% | 25% |

### 3.3 私教/企业内训
- 讲师与平台 7:3 分成；
- 平台负责销售线索、合同、收款、发票；
- 讲师按约定时间交付。

### 3.4 结算周期
- 用户购买后 7 天无理由退款期结束后结算；
- 每月 1-5 日发起提现，10 日到账；
- 讲师收益进入「讲师钱包」，可提现到银行卡。

## 4. 平台呈现

### 4.1 课程卡片（已存在，需扩展字段）
- 显示：讲师头像/昵称、课程评分、学习人数、价格、分润标签（如「支持创作者分成」）。
- 增加「讲师主页」入口。

### 4.2 讲师主页 `/courses/instructor/[slug]`
- 讲师简介、擅长领域、代表作品；
- 已上架课程列表；
- 用户评价/评分；
- 「联系讲师」按钮（经平台审核后转达）。

### 4.3 讲师后台 `/instructor`
- 课程管理：创建课程、编辑课时、设置价格、查看审核状态；
- 数据中心：销售额、订单数、完课率、退款率；
- 收益中心：待结算、已结算、可提现、分润明细；
- 资料管理：收款账户、发票信息、合同协议。

### 4.4 用户购买流程
```
用户浏览课程 → 点击购买 → 选择支付方式 → 支付成功 → 解锁课程
        ↓
订单进入「7 天无理由退款期」→ 退款期结束 → 讲师收益计入「待结算」
        ↓
次月 1-5 日讲师发起提现 → 平台审核 → 10 日到账
```

## 5. 后端数据表设计（建议）

| 字段 | 类型 | 说明 |

## 6. 与 InkCore 的协同

课程中可推荐的数字商品（如课件、模板、脚本）可通过后台 API 上架到 InkCore 销售，讲师收益回流 OPC 讲师钱包。该功能待 InkCore 上线后联调。
