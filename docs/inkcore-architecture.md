# InkCore 与 OPC 关系架构决策

> **决策项：** OPC 中新数据港平台 vs InkCore 新加坡数字商品平台 —— 两者为独立项目，仅通过 API 连通
> **核心原则：** 品牌独立、代码独立、数据库独立、运营独立，最小化 API 耦合
> **分析日期：** 2026-06-07（品牌更新：2026-06-13 墨核/MOHE → InkCore）
> **CEO：** 团坐009

---

## 一、核心定位：两个独立项目

**OPC 平台 = 中国 B2B 创业服务平台**
- 独立项目、独立品牌、独立运营
- 服务创业者、创作者、企业
- 核心功能：数字员工、任务大厅、创作者工具、数字产品仓库

**InkCore = 新加坡 C2C 数字商品交易平台**
- 独立项目、独立品牌、独立运营
- 面向东南亚消费者（TikTok 用户等）
- 核心功能：数字商品展示、支付、交付、客服

**连接方式 = 最小化 API 接口（后台连通）**
- OPC 创作者在 OPC 后台一键上架商品到 InkCore
- InkCore 销售收益回流 OPC 创作者钱包，方便变现
- 两个平台各自独立，不共享数据库、不共享前端、不共享代码库
- 仅通过少量 API 接口交互：产品上架、收益回流、账号验证

## 二、为什么必须是独立项目？

### 2.1 品牌定位完全不同
| 维度 | OPC 中新数据港 | InkCore |
|------|----------------|---------|
| **目标用户** | 创业者、创作者、企业（B2B） | 消费者、个人买家（C2C） |
| **品牌调性** | 专业、商务、B2B | 年轻、创意、数字商品 |
| **核心功能** | 数字员工、任务大厅、创作工具 | 商品浏览、支付、下载 |
| **合规环境** | 中国等保2.0 | 新加坡 PDPA |
| **货币** | 人民币 | SGD/USD |
| **支付** | 微信/支付宝 | Stripe/PayNow |

### 2.2 合规安全要求
| 合规要求 | 独立项目应对 |
|----------|------------|
| **中国数据不出境** | ✅ OPC 数据完全在中国，不共享给 InkCore |
| **新加坡 PDPA** | ✅ InkCore 数据在新加坡，不共享给 OPC |
| **中国外汇管制** | ✅ 两个平台各自结算，人民币与 SGD 不互通 |
| **GST（新加坡消费税）** | ✅ InkCore 独立报税，OPC 不受影响 |
| **等保2.0** | ✅ OPC 独立过等保，不受 InkCore 影响 |

### 2.3 成本与灵活性
| 方案 | 成本 | 灵活性 | 推荐 |
|------|------|--------|------|
| 完全合并（一个平台） | 低 | 极差 | ❌ 品牌冲突、合规风险 |
| 技术共享（统一代码库） | 中 | 差 | ❌ 耦合太高，迭代互相拖累 |
| **独立项目 + API 连通** | **中** | **高** | ✅ **推荐** |
| 完全独立（无连通） | 高 | 高 | ❌ 创作者无法变现 |

**推荐方案：独立项目 + API 连通**
- 两个项目各自独立开发、独立部署、独立迭代
- 仅通过最小化 API 交互，保持松耦合
- OPC 创作者可以方便地把商品上架到 InkCore 变现
- InkCore 销售收益回流 OPC 钱包，统一提现

## 三、技术架构：独立项目 + API 连通

### 3.1 整体架构

```
┌─────────────────────────┐         ┌─────────────────────────┐
│   OPC 中新数据港（中国）   │         │   InkCore（新加坡）     │
│   B2B 创业服务平台         │         │   C2C 数字商品平台       │
│                         │         │                         │
│  ┌──────────────────┐   │         │  ┌──────────────────┐   │
│  │ 前端：Next.js     │   │         │  │ 前端：Next.js     │   │
│  │ 域名：csdport.cn │   │         │  │ 域名：inkcore.sg │   │
│  │ 部署：阿里云       │   │         │  │ 部署：AWS SG     │   │
│  └──────────────────┘   │         │  └──────────────────┘   │
│                         │         │                         │
│  ┌──────────────────┐   │         │  ┌──────────────────┐   │
│  │ 后端：Node.js    │   │         │  │ 后端：Node.js    │   │
│  │ 数据库：PG 中国   │   │         │  │ 数据库：PG 新加坡 │   │

│  └──────────────────┘   │         │  └──────────────────┘   │

│  │ 数字产品仓库        │   │         │  │ 商品/订单/支付    │   │
│  │ 创作者生产工具      │   │         │  │ 消费者前台        │   │
│  │ 数字员工集群        │   │         │  │ 卖家后台          │   │
│  └──────────────────┘   │         │  └──────────────────┘   │
└─────────────────────────┘         └─────────────────────────┘
           │                                   ▲
           │                                   │
           │     ┌─────────────────────┐      │
           │     │   API 连通层（后台）  │      │
           │     │                     │      │
           └────▶│  1. 产品上架 API     │──────┘
                 │     OPC → InkCore    │
                 │                     │
                 │  2. 收益回流 API     │
                 │     InkCore → OPC    │
                 │                     │
                 │  3. 账号验证 API     │
                 │     双向认证         │
                 └─────────────────────┘
```

### 3.2 关键原则：最小化耦合

**两个项目独立：**
- 独立代码库（可以各自用不同技术栈，当前都是 Next.js+Node）
- 独立数据库（中国 PG vs 新加坡 PG，完全不共享）
- 独立部署（阿里云 vs AWS Singapore）
- 独立运维团队（可以各自迭代，互不阻塞）

**API 连通（仅3个接口）：**
1. **产品上架 API**：OPC 创作者后台 → 调用 InkCore API → 商品上架
2. **收益回流 API**：InkCore 订单完成 → 调用 OPC API → 收益汇入创作者钱包
3. **账号验证 API**：InkCore 登录时 → 调用 OPC SSO → 验证账号

**数据不共享：**
- OPC 数据库不含 InkCore 商品/订单数据
- InkCore 数据库不含 OPC 任务/数字员工数据
- 仅通过 API 传输必要数据（商品元数据、收益金额、账号token）

## 五、支付与货币（独立）

```
OPC 中国（人民币）                    InkCore 新加坡（SGD/USD）
┌──────────────┐                      ┌──────────────┐
│ 微信支付     │                      │ Stripe       │
│ 支付宝      │                      │ PayNow       │
│ 银联        │                      │ GrabPay      │
│ 企业对公    │                      │ PayPal       │
└──────────────┘                      └──────────────┘
       │                                   │
       │    ┌─────────────────────────┐   │
       └───▶│  各自独立，不互通        │◀──┘
            │  · 人民币钱包 = OPC     │
            │  · SGD 钱包 = InkCore   │
            │  · 汇率转换仅用于展示    │
            └─────────────────────────┘
```

**关键规则：**
- OPC 钱包只存人民币，InkCore 钱包只存 SGD
- 两个钱包不互通（避免外汇管制问题）
- 创作者在 OPC 赚人民币，在 InkCore 赚 SGD，分开提现
- 收益回流时只传金额数据，不涉及实际资金跨境转移
